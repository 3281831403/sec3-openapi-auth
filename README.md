接口文档里几条路径忘了声明鉴权，网关照着文档放开，几个删数据的接口就裸奔上线了：每个操作最终都必须能解析出明确的鉴权要求，未声明鉴权的操作必须出现在问题列表，文档里不允许存在既无鉴权又无显式豁免的操作；全局声明必须能被路径级和操作级声明覆盖，操作级优先于路径级；文档还必须给出全局鉴权声明，缺失时文档校验要报问题；空鉴权数组既不是鉴权声明也不是显式豁免，显式豁免只认操作上的 x-security-exempt 为真；声明了鉴权而实现没有校验必须报错，鉴权要求引用的方案必须已在文档中定义；批量校验时每份文档各自计算，后一份不得沿用前一份的结论，同一份文档连续两次校验必须得到相同结果。
